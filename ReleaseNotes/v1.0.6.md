# iTruVoice engine update: two new voices, Spanish fixes

Upstream tv-decomp `38edfc3` (three commits past the old `736d82f` pin),
all measured against the built engine on the host.

**Two new voices, twenty-two total.** Frank joins the English list at
index 10, a deep male voice from the MindMaker TextAssist build of
TruVoice. Francisco joins the Spanish list at index 21. Everything after
Frank shifted one index, so Pedro is now 11 through Isabel at 20.

**Your saved voices keep speaking the same person.** Provider identifiers
now carry the voice name instead of its number, so an upstream renumber
can never revoice anybody: Pedro stays Pedro whatever his index is. The
old numeric identifiers translate once (0-9 unchanged, 10-19 were Pedro
through Isabel), so nothing already picked goes silent either.

**Spanish engine fixes, free with the update.** The high-rate table
overrun is fixed (past 253 wpm the Spanish engine used to collapse a
sentence into a tenth of a second; durations now scale down sanely to
40% by 400 wpm), plus the prosody and stage-2 work that came with the
new voices.

**"TruVoice" is now two words, like "VoiceOver" already was.** Upstream
teaches the library to split CamelCase in the text itself, so the speak
window, the SAPI voice and NVDA-style readers finally agree. The corpus
proves it: eight of nine lines are byte-identical, and the ninth --
"Hello world. This is TruVoice speaking." -- simply reads "Tru Voice"
now. The VoiceOver lexicon entry still verifies byte-identical spoken
either way, so it stays as documentation.

**Left out on purpose.** The singing score compiler (`tvtts_sing` and
friends) compiles into the library because the text pipeline now runs
through that file, but the app exposes none of it: a VoiceOver voice has
no use for sung notes. The experimental Japanese frame-driving API
(`tvtts_speak_frames` plus research data) is likewise compiled in and
unexposed -- there is no Japanese front end yet, only the means to drive
one.

Verified by the host corpus check (8 lines byte-identical, 1 line
re-recorded deliberately after reading the diff), a headless probe of
all 22 voice names, languages, rates and pitches, and the CoreChecks
suite, all passing.
