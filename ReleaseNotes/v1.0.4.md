# iTruVoice 1.0.4

Fixes two things, both of which made the app under-report itself.

**The About screen now shows the real version.** Every build this repository
has cut said **1.0.0 (1)** while the tags reached 1.0.3, because xtool has no
version field — the `version: 1` in `xtool.yml` is the schema version, not
the app's. The About screen reads `CFBundleShortVersionString` and
`CFBundleVersion`, so it was misreporting to the one person who reports bugs
by version. Both plists are now stamped from the tag while the bundle is
unpacked, the app and its embedded extension are stamped together (Apple
rejects a mismatch), and the build refuses to continue if the stamp did not
land or if the two disagree.

**The preview speaks the text the way VoiceOver does.** The ellipsis fix
already ran in the provider extension, but the app's own preview handed the
engine the text as typed — so the same notification spoke correctly in
VoiceOver and stopped dead in the in-app preview, which is the path you test
with. The preview now runs the same text layer.

The all-caps section headers are gone as well; the engine spells an all-caps
run letter by letter, so "Your voice settings" was being read out as a string
of capitals by the app's own voice.

Verified by the host corpus check (9 lines, all golden) and the CoreChecks
suite, which now covers the ellipsis fold, the truncated-URL notification, and
the `&hellip;` entity.
