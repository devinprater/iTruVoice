# iTruVoice 1.0.5

Three engine-layer fixes, all measured against the built engine.

**Your name, said right.** The engine stressed the second syllable
("dev-IN") while Kevin takes the first. The user lexicon now pins Devin to
Kevin-with-a-D, one entry covering every casing, and the possessive comes
along ("Devin's" reads with the same stress). The old Linux entry is gone:
title-case already read exactly as lowercase, and all-caps spell-out happens
before the lexicon can ever see the word.

**"VoiceOver", said as two words.** The compound read as voice plus "eover".
It now speaks with exactly the phonemes two-word "voice over" does, verified
byte-identical on every casing.

**Twice as loud.** The engine peaks at 30–74% of full scale across the ten
voices, so full volume sat below Alex and Keynote Gold. A base lift doubles
every path — VoiceOver and preview alike — with VoiceOver's own volume still
scaling above it, and volume 0 still silencing.

Verified by the host corpus check and the CoreChecks suite, which now pins
the boost and its clamping.
