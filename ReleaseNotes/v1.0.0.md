# iTruVoice 1.0.0

Centigram's TruVoice — the Microsoft Agent-era voice — as an iOS app with
ten system-wide English voices: Peter, Sidney, Eager Eddie, Deep Douglas,
Biff, Grandpa Amos, Melvin, Alex, Wanda and Julia.

Install the app and the voices appear for VoiceOver and Spoken Content, with
full VoiceOver support: rate and pitch sliders and SSML prosody are honored
per piece (neutral is each voice's own default), pauses become silence,
marks report exact positions, and volume is applied as gain.

The engine is OpenTV (pinned), verified by a 9-line speech corpus with golden
sample counts plus 22 SSML/parameter checks on every build.

Note: the voice tables are Centigram's (see NOTICE.md in the repo); our code
is MIT.
