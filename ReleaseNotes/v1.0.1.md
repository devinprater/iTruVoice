# iTruVoice 1.0.1

Fixes installing 1.0.0, which iOS refused: the provider extension shipped
with unsubstituted `$(PRODUCT_…)` variables in its Info.plist, so its bundle
ID was not under the app's. Extension identifiers are literal now
(`com.devin.itruvoice.provider`), and both workflows gate on it — no raw
variables, and the extension ID under the app ID — so this cannot ship again.

If you installed nothing yet, this is the one to take: the full 1.0.0
feature set (ten voices, VoiceOver rate/pitch/prosody, marks, pauses) with
an installer that opens the door.
